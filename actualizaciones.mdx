Las actualizaciones de HWD POS deben realizarse desde la interfaz del sistema.

<Warning>
  Antes de instalar una actualización, realice una copia de seguridad de la base de datos desde **Sistema → Respaldos de base de datos**.
</Warning>

## Procedimiento de actualización

<Steps>
  <Step title="Inicie sesión como administrador">
    Ingrese a HWD POS con una cuenta que tenga permisos administrativos.
  </Step>
  <Step title="Abra el módulo de actualizaciones">
    Vaya a **Sistema → Actualizaciones**.
  </Step>
  <Step title="Seleccione el paquete">
    Elija el paquete de actualización proporcionado por el proveedor.
  </Step>
  <Step title="Cargue el paquete">
    Cargue el paquete en el sistema.
  </Step>
  <Step title="Espere la instalación">
    Espere a que HWD POS valide e instale la actualización.
  </Step>
  <Step title="Verifique el sistema">
    Compruebe que el sistema funcione correctamente después de finalizar.
  </Step>
</Steps>

## Qué toca una actualización y qué no

| Se actualiza | No se toca |
| --- | --- |
| El código del sistema: `app`, `config`, `resources`, `public`, `database` y `scripts`. | Los **complementos** (`plugins/`) y sus datos. |
| La estructura de la base de datos (migraciones). | La configuración del servidor (`storage/config.php`). |
|  | Las subidas: fotos, logos y firmas. |

Los complementos se actualizan por su propia pantalla, subiendo su `.zip`.

<Note>
  Tras una actualización que cambie los servicios de fondo, reinícielos **una vez**: `hwdpanel` →
  opción **17**. Los servicios recogen el código nuevo por su cuenta, pero reiniciarlos una vez cierra
  cualquier proceso que quedara con el código anterior.
</Note>

## Reejecutar el instalador

Es seguro y **no borra datos**: vuelve a poner permisos, configuración del servidor web, servicios y
cortafuegos en su sitio. Es la forma más rápida de arreglar un servidor al que le cambiaron algo, y
también la forma de cambiar el [puerto del sitio](/puerto).

```bash
sudo bash /var/www/HWDPOS/deploy/install-ubuntu.sh        # Ubuntu / Debian
sudo bash /var/www/HWDPOS/deploy/install-almalinux.sh     # AlmaLinux / Rocky / RHEL
```
