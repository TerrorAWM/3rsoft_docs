Resumen de los comandos más utilizados para operar y mantener un servidor HWD POS. Todos requieren acceso al servidor con privilegios de administrador (`root`/`sudo`).

## Gestión de servicios

```bash
# Estado
sudo systemctl status nginx
sudo systemctl status php8.3-fpm
sudo systemctl status hwpos-print

# Reiniciar
sudo systemctl restart nginx
sudo systemctl restart php8.3-fpm
sudo systemctl restart hwpos-print
```

<Note>
  Sustituya `php8.3-fpm` por la versión de PHP-FPM realmente instalada (por ejemplo `php8.2-fpm`). El diagnóstico [`check.sh`](/diagnostico) detecta la versión real en uso. También puede iniciar, detener o reiniciar estos servicios desde [`hwdpanel`](/hwdpanel).
</Note>

## Registros (logs)

```bash
# Actividad del worker de impresión en tiempo real
sudo journalctl -u hwpos-print -f

# Últimas entradas de un servicio
sudo journalctl -u nginx -n 100 --no-pager
```

## Respaldo y restauración de la base de datos

La forma recomendada de respaldar es desde la interfaz (**Sistema → Respaldos de base de datos**). Desde la línea de comandos puede usar `mysqldump`. Consulte el nombre de la base de datos y el usuario con `hwd-admin.php db-info` o en [`hwdpanel`](/hwdpanel).

```bash
# Respaldar (solicitará la contraseña de forma interactiva)
mysqldump -u <DB_USER> -p <DB_NAME> > respaldo-hwdpos.sql

# Restaurar
mysql -u <DB_USER> -p <DB_NAME> < respaldo-hwdpos.sql
```

<Warning>
  Use la opción `-p` **sin** escribir la contraseña en el comando; el sistema la solicitará de forma interactiva para no dejarla registrada en el historial del terminal. Restaurar sobrescribe los datos actuales: realice un respaldo antes.
</Warning>

## Diagnóstico y panel

```bash
# Diagnóstico completo
sudo bash /var/www/HWDPOS/deploy/check.sh

# Solo el informe
sudo CHECK_ONLY=1 bash /var/www/HWDPOS/deploy/check.sh

# Panel de administración
sudo hwdpanel
```

## Comprobaciones rápidas

```bash
# ¿Está libre el puerto 80?
sudo ss -ltnp 'sport = :80'

# Comprobar un paquete de extensión de PHP (usa la versión real de PHP-FPM)
dpkg -s php8.3-<extension>
```
