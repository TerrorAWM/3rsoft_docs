Resumen de los comandos más utilizados para operar y mantener un servidor HWD POS. Todos requieren acceso al servidor con privilegios de administrador (`root`/`sudo`).

## Gestión de servicios

Los nombres de los servicios cambian según el sistema.

<CodeGroup>

```bash Ubuntu / Debian
# Estado
sudo systemctl status apache2 php8.3-fpm hwpos-print hwpos-plugins

# Reiniciar
sudo systemctl restart apache2 php8.3-fpm hwpos-print hwpos-plugins
```

```bash AlmaLinux / Rocky / RHEL
# Estado
sudo systemctl status httpd php-fpm hwpos-print hwpos-plugins

# Reiniciar
sudo systemctl restart httpd php-fpm hwpos-print hwpos-plugins
```

</CodeGroup>

<Note>
  En Ubuntu, sustituya `php8.3-fpm` por la versión realmente instalada; en AlmaLinux el servicio es
  `php-fpm`, sin versión. Si usa Nginx en lugar de Apache, cambie `apache2` o `httpd` por `nginx`. El
  diagnóstico [`check.sh`](/diagnostico) detecta lo que corresponde. También puede reiniciarlos todos
  desde [`hwdpanel`](/hwdpanel) con la opción 17.
</Note>

## Registros (logs)

```bash
# Actividad de los dos servicios de fondo en tiempo real
sudo journalctl -u hwpos-print -u hwpos-plugins -f

# Últimas entradas de un servicio
sudo journalctl -u apache2 -n 100 --no-pager      # httpd en AlmaLinux
```

<Tip>
  `hwdpanel` opción **18** muestra las últimas entradas de los dos servicios de fondo juntas.
</Tip>

## Respaldo y restauración de la base de datos

La forma recomendada de respaldar es desde la interfaz (**Sistema → Respaldos de base de datos**). Desde la línea de comandos puede usar `mysqldump`. Consulte el nombre de la base de datos y el usuario con `hwd-admin.php db-info` o en [`hwdpanel`](/hwdpanel).

```bash
# Respaldar (solicitará la contraseña de forma interactiva)
mysqldump -u <DB_USER> -p <DB_NAME> > respaldo-hwdpos.sql

# Restaurar
mysql -u <DB_USER> -p <DB_NAME> < respaldo-hwdpos.sql
```

<Warning>
  Use la opción `-p` **sin** escribir la contraseña en el comando; el sistema la solicitará de forma interactiva para no dejarla registrada en el historial del terminal. Restaurar sobrescribe los datos actuales: realice un respaldo antes.
</Warning>

## Diagnóstico y panel

```bash
# Diagnóstico completo
sudo bash /var/www/HWDPOS/deploy/check.sh

# Solo el informe
sudo CHECK_ONLY=1 bash /var/www/HWDPOS/deploy/check.sh

# Panel de administración
sudo hwdpanel
```

## Comprobaciones rápidas

```bash
# ¿Está escuchando el puerto del sitio?
sudo ss -ltnp 'sport = :80'          # cambie 80 por su puerto

# Comprobar una extensión de PHP
dpkg -s php8.3-<extension>           # Ubuntu / Debian
rpm -q php-<extension>               # AlmaLinux / Rocky / RHEL

# Extensiones cargadas, en cualquier sistema
php -m
```

<Note>
  En AlmaLinux, `pdo_mysql` viene dentro de **`php-mysqlnd`**: el paquete `php-mysql` no existe.
</Note>
