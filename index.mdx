Bienvenido a la documentación de **HWD POS**. Aquí encontrará cómo instalar el sistema por red en
Ubuntu o en AlmaLinux, diagnosticar y reparar sus componentes, administrarlo con `hwdpanel`, configurar
la impresión y actualizar una instalación existente.

## ¿Qué incluye HWD POS?

HWD POS es un sistema **PHP nativo**: no usa framework, ni Composer, ni Node, ni Docker.

<CardGroup cols={2}>
  <Card title="Servidor web" icon="server">
    Apache o Nginx con PHP-FPM (PHP 8.2 o superior) sirven la aplicación. Se usa el que ya esté
    instalado; si no hay ninguno, se instala Apache.
  </Card>

  <Card title="Base de datos" icon="database">
    MariaDB 10.4 o superior almacena la información del punto de venta.
  </Card>

  <Card title="Impresión" icon="print">
    CUPS, Chromium y el servicio `hwpos-print` gestionan la cola de impresión.
  </Card>

  <Card title="Administración" icon="terminal">
    El panel `hwdpanel` administra el servidor sin usar la interfaz web.
  </Card>
</CardGroup>

## Instalación rápida

Un solo comando, en Ubuntu o en AlmaLinux: el script detecta el sistema y usa el instalador que
corresponde.

```bash
curl -fsSL https://3r.com.pa/hwdpos_inst/bootstrap.sh | sudo bash
```

Durante la instalación se pregunta el **modo** (todo en uno, solo web o solo base de datos) y el
**puerto** del sitio, que es `80` si no indica otro.

<Note>
  Antes de empezar, revise los [requisitos previos](/requisitos). Si prefiere auditar el script antes de
  ejecutarlo como root, consulte la
  [recomendación de seguridad](/requisitos#recomendación-de-seguridad-al-ejecutar-scripts).
</Note>

<Warning>
  Si instala sobre **AlmaLinux, Rocky, RHEL o CentOS**, lea antes
  [AlmaLinux, Rocky y CentOS](/almalinux): SELinux está activo de fábrica y es el paso que decide si la
  instalación funciona de verdad.
</Warning>
