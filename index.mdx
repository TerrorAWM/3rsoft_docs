Bienvenido a la documentación de **HWD POS**. Aquí encontrará cómo instalar el sistema por red, diagnosticar y reparar sus componentes, administrarlo con `hwdpanel`, configurar la impresión y actualizar una instalación existente.

## ¿Qué incluye HWD POS?

HWD POS se despliega sobre Ubuntu e integra los siguientes componentes:

<CardGroup cols={2}>
  <Card title="Servidor web" icon="server">
    Nginx y PHP-FPM (PHP 8.2 u 8.3) sirven la aplicación.
  </Card>

  <Card title="Base de datos" icon="database">
    MariaDB almacena la información del punto de venta.
  </Card>

  <Card title="Impresión" icon="print">
    CUPS, Chromium y el worker `hwpos-print` gestionan la cola de impresión.
  </Card>

  <Card title="Administración" icon="terminal">
    El panel `hwdpanel` administra el servidor sin usar la interfaz web.
  </Card>
</CardGroup>

## Instalación rápida

Instalación completa con la configuración predeterminada:

```bash
curl -fsSL https://3r.com.pa/hwdpos_inst/bootstrap.sh | sudo bash
```

<Note>
  Antes de empezar, revise los [requisitos previos](/requisitos). Si prefiere auditar el script antes de ejecutarlo como root, consulte la [recomendación de seguridad](/requisitos#recomendación-de-seguridad-al-ejecutar-scripts).
</Note>
